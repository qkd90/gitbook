# 微服务

## 章节定位

微服务章节记录从传统 Spring Boot 应用升级到 Spring Cloud 架构时涉及的注册发现、配置中心、服务调用、网关、限流、熔断和链路治理经验。

## 核心能力

```text
服务治理
  ├─ 注册中心
  ├─ 配置中心
  ├─ 服务发现
  └─ 健康检查

服务调用
  ├─ HTTP/RPC 调用
  ├─ 超时和重试
  ├─ 负载均衡
  └─ 接口兼容

稳定性
  ├─ 限流
  ├─ 熔断
  ├─ 降级
  └─ 灰度发布
```

## 推荐阅读顺序

1. 搭建 Nacos，理解注册中心和配置中心。
2. 阅读 Spring Cloud 入门材料，熟悉微服务组件。
3. 结合公司项目升级经验，理解改造风险和落地步骤。
4. 回到分布式理论章节，补充 CAP、一致性、分布式事务等基础。

## 落地关注点

- 服务拆分不能只按表拆，要按业务边界拆。
- 接口要保持向后兼容，避免一次发布影响多个服务。
- 调用链路要有超时、重试和降级策略。
- 配置中心要区分环境，敏感配置要控制权限。
- 微服务数量增加后，日志、链路追踪、监控必须同步建设。
