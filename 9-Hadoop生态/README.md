# Hadoop 生态

Hadoop 是大数据处理的基石。本章节涵盖 Hadoop 生态系统的核心组件，包括 HDFS 分布式文件系统、MapReduce 计算框架和 YARN 资源管理器。

## 学习路径

```
Hadoop简介 → HDFS核心概念 → MapReduce编程模型 → Hadoop环境搭建
                                      ↓
                          HDFS常用命令 → HDFS Java API
```
