# 信创相关

## 章节定位

本章节整理国产数据库和信创环境适配经验，当前包含达梦、OceanBase、openGauss 等数据库。重点关注语法兼容、驱动连接、迁移改造、性能调优和运维差异。

## 关注方向

```text
数据库适配
  ├─ JDBC 驱动
  ├─ 数据类型
  ├─ SQL 方言
  ├─ 分页语法
  └─ 函数兼容

数据迁移
  ├─ 表结构转换
  ├─ 数据导入导出
  ├─ 编码和字符集
  └─ 序列、自增、主键

运维部署
  ├─ 安装部署
  ├─ 备份恢复
  ├─ 监控告警
  └─ 性能参数
```

## 迁移检查清单

- 字段类型是否兼容。
- 主键、自增、序列是否需要改造。
- 分页 SQL 是否兼容。
- 日期函数、字符串函数是否兼容。
- 索引和执行计划是否符合预期。
- JDBC URL、驱动类、连接池配置是否正确。
- 批量导入导出工具是否验证。
