# 区块链相关技术

## 章节定位

本章节记录联盟链相关实践，主要包含 Hyperledger Fabric 和 FISCO BCOS 的环境搭建、测试网络、SDK 使用和部署经验。

## 技术地图

```text
联盟链基础
  ├─ 账户和证书
  ├─ 节点和组织
  ├─ 共识机制
  ├─ 智能合约
  └─ SDK 调用

Hyperledger Fabric
  ├─ 测试网络
  ├─ Chaincode
  ├─ Peer / Orderer
  └─ Cello

FISCO BCOS
  ├─ 节点部署
  ├─ 控制台
  └─ Java SDK
```

## 学习建议

先理解联盟链和公链的差异，再搭建测试网络。实践时重点记录节点证书、端口、配置文件、合约部署、交易提交和查询验证过程。

## 常见问题方向

- 证书路径错误。
- 节点网络不通。
- 合约部署失败。
- SDK 连接配置错误。
- 交易提交成功但查询不到数据。
