# Hyperledger Fabric 区块链

## 章节定位

本目录整理 Hyperledger Fabric 测试网络、Fabric 环境搭建、Chaincode、Cello 和部署实践。

## 核心概念

- Organization：组织。
- Peer：背书和账本节点。
- Orderer：排序节点。
- Channel：通道。
- Chaincode：智能合约。
- MSP：成员身份服务。

## 学习顺序

1. 使用 Fabric 测试网络。
2. 理解组织、节点、通道和证书。
3. 部署和调用 Chaincode。
4. 阅读 Fabric 网络部署教程。
5. 扩展到 Cello 或实际联盟链部署。

## 排查重点

- 证书和 MSP 路径。
- Docker 容器状态。
- Peer 和 Orderer 日志。
- 通道配置。
- Chaincode 安装、批准和提交状态。
