# FISCO BCOS 区块链

## 章节定位

本目录用于记录 FISCO BCOS 部署、控制台、智能合约和 Java SDK 调用。FISCO BCOS 常用于联盟链、政企协作、可信存证和业务数据上链场景。

## 学习路线

```text
节点部署
  ↓
控制台连接
  ↓
合约编译和部署
  ↓
Java SDK 调用
  ↓
业务系统集成
```

## Java SDK 关注点

- 节点连接配置。
- 证书路径。
- 群组 ID。
- 合约地址。
- 交易回执。
- 异常和超时处理。

## 常见问题

- SDK 连接失败：检查节点地址、端口、证书。
- 合约调用失败：检查合约地址、ABI、方法参数。
- 交易不上链：检查节点状态、群组状态和回执错误信息。
