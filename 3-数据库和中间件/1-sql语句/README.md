# SQL 语句

## 章节定位

本目录用于整理 SQL 基础、窗口函数、经典题目和业务场景题。SQL 是数据库开发、数据分析、数仓建模和报表开发的共同基础。

## 学习顺序

```text
基础查询
  ↓
JOIN 多表关联
  ↓
GROUP BY 聚合
  ↓
子查询和临时表
  ↓
窗口函数
  ↓
业务场景题和性能优化
```

## 练习重点

- 明确表之间的业务关系。
- 先写出可读 SQL，再考虑性能优化。
- 对复杂题目先拆成中间结果。
- 熟练使用 `row_number`、`rank`、`dense_rank`、`lag`、`lead`。
- 注意空值、重复数据、边界日期和一对多关联导致的数据放大。

## 排查建议

SQL 结果不对时，优先检查：

1. JOIN 条件是否缺失。
2. 聚合维度是否正确。
3. WHERE 和 HAVING 是否混用。
4. 时间范围是否包含边界。
5. 一对多关联是否导致重复计数。
