# 分布式理论

分布式系统是现代大数据架构的核心。本章节涵盖分布式系统的基础理论，包括 CAP 定理、一致性协议、分布式锁与事务等核心概念。

## 学习路径

```
分布式系统基本概念 → CAP理论 → Paxos算法 → Raft算法
                                    ↓
                    分布式锁解决方案 ← 分布式事务解决方案 ← 分布式ID生成方案
```

## 章节内容

- [分布式系统基本概念](分布式系统基本概念.md) - 分布式系统的定义、特点与挑战

- [Paxos算法](Paxos算法.md) - 经典分布式一致性算法
- [Raft算法](Raft算法.md) - 更易理解的共识算法
- [分布式锁解决方案](分布式锁解决方案.md) - 基于 Redis、ZooKeeper 等的分布式锁
- [分布式事务解决方案](分布式事务解决方案.md) - 2PC、3PC、TCC、SAGA 等模式
- [分布式ID生成方案](分布式ID生成方案.md) - 雪花算法、UUID、号段模式等
