# IDEA 快捷键操作

## 常用编辑

| 功能 | Windows 快捷键 |
| --- | --- |
| 复制当前行 | `Ctrl + D` |
| 删除当前行 | `Ctrl + Y` |
| 移动当前行 | `Alt + Shift + ↑/↓` |
| 格式化代码 | `Ctrl + Alt + L` |
| 优化 import | `Ctrl + Alt + O` |
| 大小写切换 | `Ctrl + Shift + U` |
| 多光标选择 | `Alt + 鼠标左键` |
| 选中当前行 | 鼠标三击 |

## 查找和跳转

| 功能 | Windows 快捷键 |
| --- | --- |
| 全局搜索 | `Ctrl + Shift + F` |
| 搜索文件 | `Ctrl + Shift + N` |
| 搜索类 | `Ctrl + N` |
| 搜索方法和符号 | `Ctrl + Alt + Shift + N` |
| 当前文件搜索 | `Ctrl + F` |
| 跳转定义 | `Ctrl + B` |
| 返回上一个位置 | `Ctrl + Alt + ←` |
| 查看调用层级 | `Ctrl + Alt + H` |
| 查看实现类 | `Ctrl + Alt + B` |

## 高效使用建议

- 经常使用 `Search Everywhere`：双击 `Shift`，可以搜索类、文件、动作和设置。
- 不确定某个功能快捷键时，使用 `Ctrl + Shift + A` 搜索动作名称。
- 提交前使用 `Ctrl + Alt + L` 和 `Ctrl + Alt + O` 清理格式和 import。
- 调试复杂问题时，优先使用断点、条件断点和变量求值，不要只依赖打印日志。
