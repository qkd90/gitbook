# 开发框架和工具

## 章节定位

本章节整理后端工程开发中常用的框架、工具链和项目规范，重点解决“如何把 Java 代码组织成可维护的后端项目”。

## 内容结构

```text
工程基础
  ├─ IDEA、Maven、Git、GitBook
  ├─ Java 开发规范、代码优化技巧
  └─ 项目结构设计

Spring 体系
  ├─ Spring Boot 配置文件
  ├─ 常用注解、Bean 管理
  ├─ MongoTemplate、MyBatis-Plus
  └─ 统一异常、统一返回、拦截器

业务能力
  ├─ 数据权限和租户系统
  ├─ 微信相关开发
  └─ 后端管理平台文档

日志和可观测
  ├─ Logback
  └─ Log4j2 与 Slf4j
```

## 推荐阅读顺序

1. IDEA 开发配置和快捷键。
2. Maven、Git、GitBook 目录维护。
3. Java 开发规范和项目结构设计。
4. Spring Boot 配置、注解、统一异常和统一返回。
5. MyBatis-Plus、MongoTemplate、数据权限、租户系统。
6. 日志框架和线上问题定位。

## 实战要求

每个后端项目至少应该具备：

- 清晰的包结构。
- 统一异常和统一返回。
- 参数校验。
- 日志规范。
- 数据库访问规范。
- 环境隔离配置。
- 接口联调和发布检查清单。
