## 学习建议

Java 开发者学习 Go 时，重点关注：

- Go 的错误处理方式和 Java 异常机制不同。
- Go 接口是隐式实现。
- goroutine 不是线程，channel 适合表达通信。
- context 是超时、取消和请求范围数据传递的重要机制。
- 包结构和依赖管理要保持简单，不要照搬 Java 分层。
