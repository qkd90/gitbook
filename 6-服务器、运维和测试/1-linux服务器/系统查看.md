# Linux 系统查看

## 系统版本

```bash
cat /etc/os-release
uname -a
hostnamectl
```

## CPU

```bash
lscpu
cat /proc/cpuinfo | grep "model name" | head
top
```

常看指标：

- `load average`：系统平均负载。
- `%Cpu(s)`：用户态、系统态、空闲、IO wait。
- `us` 高：业务计算较多。
- `wa` 高：磁盘 IO 等待较高。

## 内存

```bash
free -h
cat /proc/meminfo | head
```

排查内存占用：

```bash
ps aux --sort=-%mem | head
```

## 磁盘

```bash
df -h
lsblk
du -sh * | sort -h
```

查看大文件：

```bash
find /data -type f -size +500M -print
```

## 网络

```bash
ip addr
ip route
ss -lntp
ping 8.8.8.8
curl -I http://127.0.0.1:8080
```

查看端口监听：

```bash
ss -lntp | grep 8080
```

## 进程

```bash
ps -ef | grep java
top
pidstat 1
```

查看某个进程的启动命令：

```bash
tr '\0' ' ' < /proc/<pid>/cmdline
```

## 日志

系统日志：

```bash
journalctl -xe
journalctl -u 服务名 -f
```

应用日志：

```bash
tail -f app.log
tail -n 200 app.log
grep -i "error" app.log
```

## 时间

```bash
date
timedatectl
chronyc sources -v
```

设置时区：

```bash
timedatectl set-timezone Asia/Shanghai
```

## 排查顺序

服务异常时建议按这个顺序检查：

1. 服务进程是否存在。
2. 端口是否监听。
3. CPU、内存、磁盘是否异常。
4. 应用日志是否有异常堆栈。
5. 系统日志是否有 OOM、磁盘、权限、网络错误。
6. 下游数据库、中间件、第三方接口是否可访问。
