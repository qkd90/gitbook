# 测试工具

## 章节定位

本目录记录接口测试、抓包分析和联调工具，重点是 Postman 和 Fiddler。测试工具的目标是快速确认接口协议、请求参数、返回结果和网络链路。

## 常用场景

- 后端接口自测。
- 前后端联调。
- token、cookie、header 问题定位。
- 请求参数格式确认。
- 抓包分析移动端或浏览器请求。

## 工具选择

| 工具 | 适用场景 |
| --- | --- |
| Postman | REST 接口调试、环境变量、简单自动化断言 |
| Fiddler | 抓包、查看请求响应、代理移动端请求 |
| curl | 服务器上快速验证接口和网络 |

## 接口交付清单

- 正常参数能返回成功。
- 缺少必填参数时有明确提示。
- token 失效时返回鉴权错误。
- 非法 ID、越权数据、空数据都已验证。
- 分页、排序、时间范围等条件正确。
