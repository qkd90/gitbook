# 数仓项目

## 章节定位

本章节用于沉淀数据仓库项目的整体架构、分层设计、数据流转、任务调度、质量校验和指标建设经验。当前目录中已有项目架构图，可作为后续补充业务链路和技术方案的入口。

## 数仓分层

```text
ODS 原始数据层
  ↓
DWD 明细数据层
  ↓
DWS 汇总服务层
  ↓
ADS 应用数据层
  ↓
报表、接口、数据服务
```

## 建议补充内容

- 数据来源：业务库、日志、第三方接口、文件。
- 采集方式：离线同步、实时采集、增量抽取。
- 主题域：用户、订单、商品、设备、行为、财务等。
- 指标体系：原子指标、派生指标、复合指标。
- 调度体系：任务依赖、补数、失败重试、告警。
- 数据质量：空值、重复、波动、主外键一致性。
- 权限和安全：脱敏、分级、授权、审计。
