# Java 开发

## 章节定位

Java 开发是整套技术体系的基础章节，主要覆盖语言基础、工程规范、算法训练、面试题和常用后端知识点。后续 Spring Boot、微服务、大数据组件的 Java API 都建立在这一部分之上。

## 学习路径

```text
Java 基础
  ↓
面向对象、集合、异常、泛型、IO
  ↓
并发编程、JVM、常用设计模式
  ↓
代码规范、接口设计、调试能力
  ↓
算法题、剑指 Offer、LeetCode 热题
```

## 重点内容

- Java 基础语法、包装类型、日期时间、HTTP 请求类型。
- 代码规范、CRUD 概念、日常开发注意事项。
- 算法题目、动态规划、链表、二叉树、数组、字符串。
- 剑指 Offer 专项训练和 LeetCode 热题。
- PDF、xmind、docx 等资料作为扩展阅读和复习材料。

## 学习建议

先把 Java 基础和代码规范看完，再进入算法题目录。算法题不要只看答案，建议按“题目理解、暴力解法、优化思路、复杂度分析、代码实现、复盘总结”的顺序整理。

## 后续衔接

- 学完基础语法后进入 [开发框架和工具](../2-开发框架和工具/README.md)。
- 学完集合、IO、并发后进入数据库、中间件和微服务。
- 有大数据方向需求时，重点补充 Java API、序列化、网络和并发基础。
