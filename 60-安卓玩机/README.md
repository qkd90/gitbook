# 安卓玩机

## 章节定位

本章节记录个人安卓设备折腾、root、刷机和系统调试相关内容。此类操作风险较高，适合在备用设备上验证，不建议直接在主力机操作。

## 操作前准备

- 备份照片、通讯录、聊天记录和重要文件。
- 确认设备型号、系统版本和 bootloader 状态。
- 准备原厂线刷包或恢复包。
- 确认电脑驱动、ADB、Fastboot 可用。
- 了解解锁、root、刷机可能带来的保修和安全风险。

## 常见方向

- 小米手机解锁 Bootloader。
- Magisk root。
- ADB 和 Fastboot 常用命令。
- 恢复出厂、刷入 boot、修复开机循环。

## 风险提示

root 和刷机会影响系统完整性，可能导致数据丢失、无法 OTA、支付或银行类应用异常。执行前务必确认每一步命令和目标机型匹配。
